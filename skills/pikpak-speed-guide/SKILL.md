# PikPak 加速完整指南

**社区共识**：PikPak 变慢通常不是 PikPak 本身的问题，而是**运营商对 PikPak 域名的 QoS 限制**（中国大陆移动最严格：SNI 阻断 + 限速）。本指南按「成本从低到高」给出三层方案。

## 第 0 步：先诊断（避免瞎折腾）

```bash
python3 scripts/speed_diag.py
```

诊断脚本会：
1. 检查当前账号状态（是否会员——影响可用加速方案）
2. 测试到 PikPak 各域名的连通性与延迟
3. 给出针对性的方案建议

**先问用户三个问题**（判断问题类型）：
1. 什么网络？（移动 > 联通/电信 的限速更严）
2. 什么时段慢？（晚高峰 19-23 点更差 → 运营商 QoS 特征）
3. 什么操作慢？（网页下载 / 在线播放 / 第三方工具 → 不同方案）

## 三层方案（按成本从低到高）

### 方案 1：网络层（0 成本，先试）

| 措施 | 效果 | 说明 |
|------|------|------|
| 换网络测试 | 立即可判断 | 移动 → 联通/电信热点对比；若明显变快则确认是运营商问题 |
| 用代理/VPN | 常有效 | 官方 FAQ 认可：「如果使用 VPN 能获得更稳定的连接，您可以继续使用」 |
| 换 DNS | 部分有效 | 改用 223.5.5.5 等；社区实测「新加坡节点 DNS 最快」 |
| 避开晚高峰 | 缓解 | 运营商 QoS 高峰特征 |

### 方案 2：WebDAV 通道（会员功能，社区实测有效）

**核心事实**：网页/App 下载被运营商限到 2MB/s 时，**WebDAV 通道常能绕开**（CSDN 实测）。

用 `pikpak-webdav-guide` skill 完成 WebDAV 配置（需要会员）。

### 方案 3：本地加速代理（最强，需部署）

**成熟开源方案**：`pikpak-webdav-proxy`（MIT 许可，零依赖，专为中国大陆用户设计）

**实测对比**（项目作者与闭源 CloudDrive2 交叉测试）：

| 指标 | 该代理 | CloudDrive2 | 直连 WebDAV |
|------|--------|-------------|-------------|
| 顺序播放吞吐 | **10-30+ MB/s** | 3-36 MB/s | 2-5 MB/s |
| 拖动响应 TTFB | **400-850 ms** | 480-3000 ms | 数秒 |
| 拖动后重连 32MB | **0.05 s**（缓存） | ~2 s | 重付握手 |

**它解决三个根本问题**：
1. **单连接限速**（2-5MB/s）→ 16 路并发（有效速率=多连接之和）
2. **播放器拖动卡顿** → 持久连接池 + 直链缓存（80 分钟）+ 三级缓存
3. **302 交换限流** → 直链缓存避免高频请求

**部署引导**（引导用户自行部署，我们不代下载执行）：

1. 从项目 releases 下载对应平台二进制（Windows/macOS/Linux/Android/Termux 全平台）
   项目地址：https://github.com/adhksosne/pikpak-webdav-proxy
2. 确认 PikPak WebDAV 凭据已开通（设置 → 实验室功能/访问与集成 → WebDAV）
3. 运行（示例）：
   ```bash
   # macOS（Apple Silicon）
   ./pikpak-proxy-darwin-arm64 -target https://dav.mypikpak.com -user <你的WebDAV用户名> -pass <你的WebDAV密码>

   # Windows
   pikpak-proxy.exe -target https://dav.mypikpak.com -user <用户名> -pass <密码>
   ```
4. 客户端（Infuse/VidHub/WinSCP）地址改为 `http://localhost:7777`

**提醒用户**：
- 部署在公网/VPS 时务必加 `-auth-user`/`-auth-pass`（认证模式）
- 本项目是**第三方开源工具**，有风险意识（MIT 开源可审计；但我们作为引导者不替用户下载执行）
- 账号短时限速（大流量后掉速几小时）是服务端策略，任何方案都无法绕过，只能等

## 优化验收标准（给用户的预期）

| 场景 | 直连基线 | 优化目标 |
|------|---------|---------|
| 网页下载 | 2MB/s（运营商限） | 8-20MB/s（WebDAV/代理） |
| 4K 播放 | 拖动卡数秒 | 拖动 <1s |
| 离线任务拉回 | 波动大 | 10-30MB/s |

## 常见问题

**Q：用了代理为什么还慢？**
A：三种可能：① 账号级短时限速（等几小时）；② 代理并发参数没调优（默认 16 为甜点值）；③ 代理部署位置带宽不足（VPS 选大带宽）。

**Q：免费账号能加速吗？**
A：网络层方案可以；WebDAV/代理方案需要会员（WebDAV 是会员功能）。

**Q：会不会违反 PikPak 规则？**
A：网络层与 WebDAV 是官方支持的用法（官方 FAQ 认可 VPN）；本地代理属于个人使用优化，不涉及账号分享。但**不要分享账号/滥用**（官方反滥用政策）。
